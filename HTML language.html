HTML ทำงานอย่างไร?
4 ขั้นตอนหลัก
1

สร้างโครงสร้างด้วย Tags

แท็ก HTML เป็นคำสั่งในเครื่องหมาย < > บอกเบราว์เซอร์ว่าเนื้อหาชิ้นนี้คืออะไร

<h1>ยินดีต้อนรับ</h1>   <p>เนื้อหา...</p>
2

จัดวาง Element ซ้อนกัน (Nesting)

Elements สามารถซ้อนกันได้เป็นลำดับชั้น Parent → Child สร้างโครงสร้างที่ชัดเจน

<div> <h2>หัวข้อ</h2> <p>รายละเอียด</p> </div>
3

เพิ่ม Attributes เพื่อกำหนดค่า

Attributes ให้ข้อมูลเพิ่มเติมกับ Elements เช่น ลิงก์, สี, ขนาด, หรือ ID สำหรับ CSS/JS

<a href="https://example.com">คลิกที่นี่</a>
4

Browser แปลงเป็น DOM แล้วแสดงผล

เบราว์เซอร์อ่าน HTML และสร้าง Document Object Model (DOM) เพื่อแสดงผลบนหน้าจอ

<!DOCTYPE html> → Parser → DOM Tree → Render 🎨
